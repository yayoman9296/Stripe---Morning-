# Stripe---Morning-
Automates Invoices 

For all those who sell in USD but struggle to file in a foreign country this is your answer! 

Last week I took the liberty of creating a system that will take Stripe payments and automatically make invoices for those charges. 

Living in Israel, I linked Stripe to GreenInvoice (morning) to file tax reports for each charge via Stripe. 

One of my favorite features is that my system will automatically detect the currency of the transaction and as a direct result file different tax reports. 

For example: 

If a client pays in ILS through Stripe. GreenInvoice will automatically file a report for me WITH SALES TAX ALREADY INCLUDED IN THE PRICE. 

And if I get a transaction in USD or another currency it will automatically file with 0% sales tax. 

This saves me hours of manual labor. It can file while I sleep!

The best part is that this is applicable to any business model, even if you don't use Stripe. As long as your method of payment has available API. This is THE move. 

I'm included the code I used in the repo if anyone is interested in replicating this for their own business or for a clients.
